# AWS Nginx Deployment

This project demonstrates deploying a static website using Nginx on an AWS EC2 server.

## Tech Stack
- AWS EC2
- Nginx
- Ubuntu Linux
- GitHub

## Architecture

Developer → GitHub → EC2 → Nginx → Website

## Deployment Steps

1. Launch EC2 instance
2. Connect using SSH
3. Install Nginx
4. Clone GitHub repository
5. Deploy index.html
6. Restart Nginx
