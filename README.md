# AWS Nginx Deployment

This project demonstrates how to deploy a static website on an AWS EC2 server using Nginx.

## Tech Stack
- AWS EC2
- Nginx
- Ubuntu
- GitHub

## Project Architecture

Developer → GitHub → AWS EC2 → Nginx → Website

## Deployment Steps

1. Launch EC2 instance (Ubuntu)
2. Connect to server using SSH
3. Install Nginx
4. Clone GitHub repository
5. Copy website files to Nginx directory
6. Restart Nginx server
7. Access website using public IP
